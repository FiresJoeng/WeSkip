# WeSkip
Windows 微信小程序跳广告 | WeChatAppEx.exe ADs Skipper

### 前言
最近在玩腾子家的微信小游戏, 发现广告是真多. 本想依靠万能的某宝某鱼来屏蔽或者跳过广告, 好家伙没想到这帮只会"易语言"的杂种卖个三无报毒脚本, 还要按天卡周卡这样卖, 一气之下打算自己写一个并且开源! 

### 如何使用
使用方法如下:
```
1. 克隆仓库
2. 配置环境
3. 编译DLL
4. 以管理员身份执行 main.py
5. 在可视化窗口内操作
```
